## 📋 Sobre o Projeto
Este projeto foi desenvolvido para resolver a ausência de um sistema centralizado de chamados na empresa. Anteriormente, as solicitações eram feitas presencialmente ou por e-mail, gerando falta de histórico, esquecimentos e pouca visibilidade sobre o andamento das demandas.

Para resolver esse problema, foi implementada uma solução de baixo custo aproveitando a infraestrutura existente (servidor **TrueNAS**), combinando o **NocoDB** para interface/banco de dados, o **n8n** para orquestração de fluxos e automações, e o **Power BI** para inteligência de dados.
